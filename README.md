# Бот земельных новостей для Telegram-канала

Каждый день бот сам находит свежую новость о земельном законодательстве или земельном рынке, пересказывает её своими словами с помощью нейросети **Qwen** и публикует в ваш канал. **В постах нет ссылок, названий СМИ и указаний на источники**, только суть новости.

Всё бесплатно: бот работает на серверах **GitHub**, нейросеть Qwen запускается там же. Свой сервер, ключи и оплата не нужны.

## Как выглядит пост

> **🏡 Раздел участков ИЖС станет проще**
>
> Госдума приняла закон, который упрощает раздел участков под ИЖС…
>
> Новые правила начнут действовать с 1 марта. Владельцам стоит заранее проверить границы участка в ЕГРН…
>
> #законодательство #ИЖС

## Что умеет

- Собирает новости из RSS-лент (список в `feeds.txt`, можно дополнять).
- Оставляет только земельную тематику: ИЖС, СНТ, ЛПХ, кадастр, Росреестр, земельный налог, цены и спрос на участки. Новости о законах идут в приоритете.
- Не повторяется: помнит опубликованное и склеивает одну новость из разных СМИ.
- Двойная защита от источников: запрет в инструкции для нейросети и автоматическая вычистка предложений со ссылками, @упоминаниями и фразами «как сообщает…».

## Запуск через GitHub (рекомендуется)

### 1. Создайте бота и подключите к каналу

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте **токен**.
2. Добавьте бота в канал **администратором** с правом «Публикация сообщений».
3. *(необязательно)* Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot) и напишите своему боту `/start`. Тогда бот будет сообщать вам об ошибках.

### 2. Загрузите бота на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com) и нажмите **New repository**.
2. Название любое, например `land-news-bot`. Тип **Public** (так серверы GitHub бесплатны без ограничений; секретные ключи всё равно никто не увидит).
3. На странице репозитория: **Add file → Upload files** и перетащите **всё содержимое** папки `land_news_bot`, включая скрытую папку `.github`.

   > ⚠️ Проводник/Finder может не показывать папку `.github`. Если она не загрузилась, создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/post.yml`, и вставьте содержимое этого файла из архива.

### 3. Добавьте секреты

**Settings → Secrets and variables → Actions → New repository secret:**

| Имя | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `CHANNEL_ID` | `@имя_канала` (или числовой ID `-100…` для закрытого канала) |
| `ADMIN_ID` | ваш Telegram ID (необязательно) |

### 4. Разрешите боту сохранять историю

**Settings → Actions → General → Workflow permissions →** выберите **Read and write permissions** → **Save**.

### 5. Проверьте

Вкладка **Actions** → **Земельные новости** → **Run workflow**. Через 5–15 минут пост появится в канале (первые минуты уходят на запуск нейросети).

Дальше бот будет публиковать пост **каждый день в 10:00 по Москве** сам.

### Настройки (по желанию)

**Settings → Secrets and variables → Actions → вкладка Variables:**

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `SIGNATURE` | подпись в конце поста, например `@my_land_channel` | нет |
| `LLM_MODEL` | модель Qwen: `qwen3:8b` (лучше) или `qwen3:4b` (быстрее) | `qwen3:8b` |
| `LOOKBACK_HOURS` | насколько свежие новости брать, часов | `48` |

**Время и частота публикаций** задаются в `.github/workflows/post.yml`, строка `cron`. Время там **в UTC** (Москва минус 3 часа):

```yaml
- cron: "0 7 * * *"     # 10:00 МСК
- cron: "0 15 * * *"    # добавьте строку, чтобы был ещё пост в 18:00 МСК
```

GitHub иногда запускает задачи с опозданием на 5–30 минут, это нормально.

### Если что-то не так

Откройте **Actions**, щёлкните по запуску с красным крестиком, затем по шагу с ошибкой. Частые причины:
- *Chat not found / Forbidden*: бот не добавлен в канал админом или неверный `CHANNEL_ID`.
- *Permission denied при сохранении истории*: не сделан пункт 4.
- *Свежих новостей нет, пост пропущен*: не ошибка, просто за последние двое суток не нашлось новых земельных новостей.

## Другие варианты нейросети

Qwen на серверах GitHub бесплатен и не требует ключей. Если хотите тексты лучше или быстрее, можно подключить облачную нейросеть: задайте переменную `LLM_PROVIDER` и добавьте ключ в секрет `OPENAI_API_KEY` (для Claude — `ANTHROPIC_API_KEY`).

| `LLM_PROVIDER` | Цена | Ключ |
|---|---|---|
| `ollama` (по умолчанию) | бесплатно | не нужен, Qwen запускается на GitHub |
| `openrouter` | бесплатные модели `:free`, в т.ч. большая Qwen3 | [openrouter.ai/keys](https://openrouter.ai/keys) |
| `gemini` | бесплатный тариф | [aistudio.google.com](https://aistudio.google.com/apikey) |
| `anthropic` | доли цента за пост, лучшее качество | [console.anthropic.com](https://console.anthropic.com) |

## Запуск на своём сервере (альтернатива GitHub)

Если хотите управлять ботом командами из Telegram (`/now`, `/preview`, `/stats`) и включить модерацию постов, запустите бота на VPS (для Qwen нужно ~8 ГБ ОЗУ):

```bash
curl -fsSL https://ollama.com/install.sh | sh && ollama pull qwen3:8b
pip install -r requirements.txt
cp .env.example .env      # заполните .env
python bot.py
```

В этом режиме время публикаций задаётся в `.env` (`POST_TIMES=10:00,18:00`), а `MODERATION=1` включает проверку постов перед публикацией.

## Настройка под себя

- **Источники**: `feeds.txt`. Подходит любая RSS-лента. Для своей темы используйте Google News: `https://news.google.com/rss/search?q=ВАШ+ЗАПРОС&hl=ru&gl=RU&ceid=RU:ru` (например, с названием региона).
- **Стиль постов**: текст `SYSTEM_PROMPT` в `bot.py` (длина, тон, эмодзи, хэштеги, призыв к действию).
- **Тематика**: списки `LAND_WORDS`, `LAW_WORDS`, `MARKET_WORDS` в `bot.py`.

Файл `news.db` — память бота о том, что уже опубликовано. GitHub обновляет его после каждого запуска; удалять его не нужно.
